# 창원경륜 출주표 → CSV

창원레포츠파크 출주표(확정/미확정)에서 창원 경주 정보를 추출해 화면에 표로 보여주고 CSV로 내려받는 Streamlit 웹앱입니다.

## 추출 항목
경주번호, 경주일, 경주시간, 선수번호, 선수명, 기수, 나이, 기어배수, 등급(경주 등급), 승률, 연대율, 200미터기록, 훈련지, 창원점수, 종합점수, 상금순위

- 경주번호 형식: `c` + 년도 + 회차(2자리) + 일차(2자리) + 경주번호(2자리) — 예: `c2026400301`

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
